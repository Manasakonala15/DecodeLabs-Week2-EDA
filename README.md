# 📈 DecodeLabs Internship – Week 2

## 🔍 Exploratory Data Analysis (EDA)

### 📌 Project Overview

This project focuses on exploring the e-commerce dataset to discover trends, patterns, and business insights using statistical analysis techniques.

### 🎯 Objectives

* Understand dataset characteristics
* Analyze sales performance
* Study customer behavior
* Identify business trends
* Detect outliers

### 🛠️ Tools & Technologies

* Python 🐍
* Pandas 📚
* NumPy 🔢
* Google Colab 💻
* Microsoft Excel 📈

### 📊 Analysis Performed

* Dataset overview
* Statistical summary
* Revenue analysis
* Product analysis
* Payment method analysis
* Order status analysis
* Referral source analysis
* Outlier detection

### 🏆 Key Insights

* Total Revenue: ₹1,264,761.96
* Average Order Value: ₹1,053.97
* Printer was the most sold product
* Chair generated the highest revenue
* Instagram was the top referral source
